如何获取 51job Cookie
推荐：使用 jshook 浏览器模式，完全不需要 Cookie。 在 Kiro 中通过 jshook 打开 51job 搜索页后，爬虫会自动使用浏览器模式。

如需手动获取 Cookie（requests 模式）：

  1. 用 Chrome 打开 we.51job.com
  2. 按 F12 → Network 标签
  3. 搜索框搜索任意关键词，触发一次请求
  4. 点击任意请求 → Request Headers → 复制 Cookie 字段
Cookie 有效期约 1-7 天，过期后需重新获取。
