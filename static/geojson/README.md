# 招聘数据可视化平台地图功能使用指南

## 地图数据结构

本项目使用的地图数据位于 `static/geojson` 目录下：

- `china.json` - 中国全国地图数据
- `province/` - 各省份地图数据，使用行政代码（adcode）命名，如 `110000.json`（北京）
- `citys/` - 各城市地图数据，也使用行政代码命名
- `location.json` - 包含地区名称与行政代码的对应关系

## 地图交互功能

地图提供以下交互功能：

1. **地图下钻**：点击地图上的区域可以下钻到更详细的地图（全国→省份→城市→区县）
2. **地图返回**：双击地图可以返回上一级地图
3. **筛选功能**：通过筛选条件可以过滤数据
4. **指标切换**：可以在平均薪资和岗位数量之间切换
5. **导出数据**：可以将排名数据导出为CSV文件

## 技术优化

本次优化主要包括：

1. **基于adcode的地图加载**：使用行政区划代码加载地图，确保准确性
2. **历史记录栈管理**：优化地图层级导航，存储地图浏览路径
3. **GeoJSON数据缓存**：减少重复加载，提升性能
4. **API接口优化**：改进了数据接口结构，更好地支持地图下钻功能

## 开发者文档

详细的API接口说明：

1. **省份城市数据接口**：`/api/province-cities?province={provinceName}`
   - 返回指定省份下的城市数据

2. **城市区县数据接口**：`/api/city-districts?province={provinceName}&city={cityName}`
   - 返回指定城市的区县数据

3. **新地图数据接口**：`/api/map/districts?city={cityName}`
   - 返回指定城市的区县数据，格式符合新的交互需求
